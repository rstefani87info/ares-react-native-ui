# Checklist Migliorie aReS React Native UI

- [1] 1. Correggere l'entrypoint del package in `package.json`: oggi `"main": "expo-router/entry"` ma `expo-router` non e' dichiarato tra le dipendenze; l'import del package lato consumer risulta fragile/non risolvibile.
- [2] 2. Allineare le dipendenze reali del runtime: i moduli importati dal codice del package vanno dichiarati in `dependencies` (es. `react-native-gesture-handler`, `react-hook-form`, `yup`, `axios`, `react-native-device-info`).
- [3] 3. Sistemare `effects/query.js`: implementazione hook `query()` non consistente con `axios` (usa `response.ok`/`response.json()` e ritorna `data` non definito), rischio di crash immediato in app consumer.
- [4] 4. Stabilizzare il supporto a `@ares/react-native-ui-dev`: `ApplicationRoot` puo' leggere `./.tmp/ares-rn-args.json` (chiave `path|component|render`) per renderizzare un componente passato da riga di comando, senza log/side effects quando non configurato.
